### About
This is my first ever Minecraft Mod made in Fabric. It adds three new ores with full tools and armor sets. The goal of ths mod is that it makes minecraft more fun by adding more options for their tools and keeping the new materials balanced.

### Learned Concepts:
- How to create an Item
- How to create a Block
- Creating Tool Sets
- Creating Armor Sets
- Adding Custom Recipes
- Ore Generation

### Materials
The mod has three main materials:

| Material          | Rarity    | Generation  | Tier       |
| ------------ | ------ | -------- | ------- |
| Tin       | Common    | Y -16 → 64  | Early Game |
| Amethyst   | Rare      | Y -48 → 0   | Late Game  |
| Obsidianite | Very Rare | Y -48 → -20 | End Game   |


### Material Progression
Wood -> Stone -> Copper -> **Tin** -> Iron -> Diamond -> **Amethyst** ->  Netherite -> **Obsidianite** 

### Crafting
Each material can be crafted into Sword, Pickaxe, Axe, Shovel, Hoe, It's Block, Helmet, Chestplate, Leggings, Boots.
